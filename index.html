방열핀 효율 계산기

일정한 단면을 가진 곧은 핀의 실제 열방출량을 핀 전체가 기저 온도일 때의 이상적인 열방출량과 비교합니다. 입력 단위를 선택하고 조건에 맞는 한 값을 구하세요.

계산할 값

0 이상

SI 변환 후 0보다 큰 값

SI 변환 후 0보다 큰 값

SI 변환 후 0보다 큰 값

0 이상

계산은 이 브라우저에서 처리합니다. 지수 표기(예: 1.2e-3)를 사용할 수 있습니다.

계산 결과

끝단 단열 핀 효율 η

—

입력 후 계산하기를 누르세요.

FORMULA

m = √(hP/(kA꜀)); η = tanh(mL)/(mL); mL → 0: η → 1

적용 조건

정상 1차원 전도, 일정한 단면·열전도율·대류계수·주위 온도, 균일한 기저 온도, 끝단 단열을 가정합니다. 횡단면 온도차·복사·접촉 열저항은 제외합니다. P는 측면 대류 면적을 만드는 둘레이며 끝단 면적은 포함하지 않습니다. h=0 또는 L=0이면 효율의 극한값 1을 표시하며 열방출량이 있다는 뜻은 아닙니다.

표시값은 부동소수점 근삿값입니다. 설계 안전계수와 입력하지 않은 오차 요인은 계산하지 않습니다.
